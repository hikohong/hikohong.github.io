# DeepSignal Sound Effects

Place the following MP3 files here to enable custom sci-fi sound effects.
If absent, the site falls back to synthesized Web Audio API sounds.

| File | Used for | Source |
|------|----------|--------|
| `click.mp3` | Nav / button clicks | freesound.org #750435 |
| `scan.mp3` | Search button | freesound.org #702805 |
| `open.mp3` | Open modal (Map/Report/Literature) | freesound.org #665222 |
| `close.mp3` | Close modal | freesound.org #220170 |
