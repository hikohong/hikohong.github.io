YouTube Ad Skip Auto-Clicker

廣告「略過」按鈕一出現就自動點掉，然後回到正片。

MIT 授權 無追蹤、無外連 零相依套件

方式一 · Chrome 擴充功能

推薦。不需要 Tampermonkey，也不需要任何第三方管理器。

⬇ 下載擴充功能 (.zip)
  1. 下載上面的 zip，解壓縮到一個你不會刪掉的資料夾。
  2. 網址列輸入 chrome://extensions 並開啟。
  3. 右上角打開 開發人員模式。
  4. 點 載入未封裝項目，選擇剛才解壓出來的資料夾。
  5. 重整 YouTube 就生效了。
為什麼不能一鍵安裝？Google 從 2018 年起已完全移除網頁端安裝擴充功能的能力， 非 Chrome Web Store 來源的 .crx 一律會被瀏覽器擋下。 「載入未封裝項目」是官方支援、也是唯一不上架就能安裝的方式。 好處是全程在你本機，沒有任何上傳或審核。

方式二 · 使用者腳本（真正一鍵）

如果你已經裝了 Tampermonkey 或 Violentmonkey，點下去就會跳出安裝視窗。

⚡ 一鍵安裝 userscript
沒有安裝管理器的話，這個連結只會顯示原始碼。 功能核心與擴充功能相同，但沒有設定面板與計數器。

它會做什麼

  • 自動點「略過廣告」——按鈕一可點就立刻點掉。
  • 快轉不可略過的廣告——把廣告拉到結尾（只在廣告播放時，絕不會動到你的正片）。
  • 廣告期間靜音，結束後還原——YouTube 的廣告與正片共用同一個播放元件， 所以靜音必須還原，否則正片會一路靜音下去。
  • 關閉橫幅廣告——影片下方的疊加式廣告。
  • 工具列面板可個別開關，並顯示已略過的廣告數。
只要求 storage 一項權限（存你的開關設定與計數）。 不連外網、不收集資料、不載入遠端程式碼。 在廣告中途你自己手動取消靜音的話，它不會跟你搶著再靜音回去。
